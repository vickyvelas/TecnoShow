# TecnoShow – catálogo web

Página de productos de TecnoShow (Mendoza). Es un solo archivo `index.html` con los datos en:

1. **Planilla "TecnoShow-mercadolibre"** (`1JwkT3fv9DmZi4esw3Fw6sgc71hg-1xOS4gS__yxFBsc`, de vicvelasco23@gmail.com)
   - Pestaña `mercadolibre`: precios, stock (Sí / No) y ofertas de los productos de Mercado Libre. Las celdas vacías no cambian nada.
2. **`public/catalogo-ml.json`**: copia de la tienda de Mercado Libre que se actualiza automáticamente.

Si un mismo código (sku) aparece en más de un lugar, gana el que está primero en esa lista.
